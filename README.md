## How to view the site
1. **Open the site locally**
   - Open `index.html` directly in a modern browser (Chrome, Safari, Edge, Firefox). The page uses React and React‑Router from CDN URLs, so an internet connection is required for those libraries, but no server‑side code is needed.
   - Alternatively, run a simple static server (e.g., `python -m http.server 8000` inside the `ecobreathe-website` folder) and navigate to `http://localhost:8000/`.

2. **Navigation**
   - The top navigation bar provides links to **Home**, **Current Conditions**, **What’s Next**, and **Maintenance**. The active link is highlighted in the primary green colour.
   - Browser back/forward buttons work because the app uses React Router’s client‑side routing.
   - Direct URLs such as `/conditions`, `/whats-next`, and `/maintenance/EcoBreathe-01` load the appropriate page without a 404 (the static server must be configured to fallback to `index.html` for unknown routes – most dev servers do this automatically).

3. **Demo data**
   - The dashboard on **Current Conditions** shows static placeholder readings labelled **DEMO DATA**. No real sensor data or secret keys are exposed.
   - The AI‑assisted insights section is also in demo mode.

4. **Maintenance passport**
   - The **Maintenance** page generates a QR code for the panel `EcoBreathe-01`. Scanning it on a mobile device opens the same maintenance page, allowing technicians to log activities.
   - Logged actions are stored only in the browser’s memory for this demo.

5. **Styling & accessibility**
   - Colours follow the exact palette you provided.
   - Typography uses Montserrat for headings, Open Sans for body text, and Source Code Pro for technical values.
   - Reduced‑motion media query respects users who prefer minimal animation.
   - All interactive elements meet minimum touch‑target sizes and have clear focus styles (inherited from the browser).
